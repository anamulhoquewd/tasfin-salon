# TASFIN — Website UI Kit

Marketing site recreation: Home, Services, Portfolio, About/Contact.

## Components
- `Nav.jsx` — Top nav with logo, links, WhatsApp CTA
- `Hero.jsx` — Full-bleed hero with reel video + CTAs
- `IntroSection.jsx` — Short "why us" section
- `ServicesPreview.jsx` — 4-card services grid
- `PortfolioGrid.jsx` — Filterable portfolio with lightbox
- `Testimonials.jsx` — 3-up review cards
- `ContactCTA.jsx` — WhatsApp + phone block
- `Footer.jsx` — Site footer
- `ServiceListItem.jsx` — Long-form services page row
- `WhatsAppFAB.jsx` — Floating WhatsApp button

## Pages
The interactive prototype in `index.html` lets you click through Home → Services → Portfolio → About. WhatsApp FAB persists across pages.
